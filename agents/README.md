# IIP Agent Operating System

These agent specifications define the initial AI workforce for the Invisible Illness Project (IIP).

## Agents

- `chief_of_staff.md` — orchestration, prioritization, status, delegation
- `research_scientist.md` — literature and evidence synthesis
- `experimental_scientist.md` — experiment design, execution, and analysis
- `software_engineer.md` — Lamina/OCPE/software engineering
- `scientific_reviewer.md` — independent scientific/technical QA
- `grant_development.md` — grants and funding proposals
- `development.md` — partnerships, fundraising, and external development
- `operations.md` — administrative and organizational operations

## Core principle

Agents produce durable artifacts, preserve provenance, and stop at explicit human-approval gates. They should never silently convert uncertainty into fact.

## Default authority

Agents may research, analyze, draft, test, simulate, and propose. Human approval is required for publication, grant submission, external commitments, production releases, material spending, scientific claims presented as established, and changes to core IIP strategy.
